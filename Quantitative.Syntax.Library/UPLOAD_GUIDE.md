# Upload Guide

1. Download and unzip `Quantitative_Syntax_Library_Starter.zip`.
2. Open the GitHub repository named `Quantitative.Syntax.Library`.
3. If the repository is empty, select **uploading an existing file**.
4. Open the unzipped `Quantitative.Syntax.Library` folder.
5. Drag everything inside that folder into GitHub.
6. Use the commit message:

   `Add quantitative syntax library structure`

7. Select **Commit changes**.

Upload the contents of the folder, not the ZIP file itself.
