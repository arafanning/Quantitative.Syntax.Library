# Attribution and Source Policy

This repository contains learning notes, links, and selected code examples related to quantitative psychology.

## For every external example

Record:

- original author or organization;
- repository or webpage title;
- direct source URL;
- access date;
- software package and version, when relevant;
- repository license, when available;
- whether the syntax was copied, adapted, or summarized.

## Preferred practice

Link to the original file and write your own annotated explanation. Reproduce only the amount of code needed to illustrate the method.

## Suggested source note

> Source: Author or Organization. Repository or resource title. URL. Accessed YYYY-MM-DD.  
> Adaptation: Describe what was changed and why.

## Important distinction

Successful code is not necessarily appropriate code. Notes should address the estimand, coding decisions, assumptions, diagnostics, and interpretation rather than only whether the script runs.
